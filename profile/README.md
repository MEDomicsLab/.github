# ❝ Who are we, MEDomicsLab?

**MEDomicsLab**, founded by **Professor Martin Vallières**, aims to improve **precision medicine** through new, clinically grounded AI tools and methods, while keeping _open source_ and _science_ in the loop.

`MEDomicsLab` is also the main laboratory behind the **MEDomics Platform**, which is a collaborative, open-source platform and solution for **medical data modeling** with one **unified dashboard** where clinicians and computer scientists work side by side to manage heterogeneous medical datasets, design and run experiments, and build predictive models.

Come give it a try @ [medomics.app](https://medomics.app/) / available on `Windows`, `Linux`, and `macOS`.
