# <img src="icons/fleur-de-lis.svg" alt="" height="32" align="absmiddle"> Who are we, MEDomicsLab?

**MEDomicsLab**, founded by [Professor Martin Vallières](https://www.mcgill.ca/medphys/martin-vallieres), aims to improve **precision medicine** through new, clinically grounded AI tools and methods, while keeping _open source_ and _science_ in the loop. _Our research laboratory started at [Université de Sherbrooke](https://www.usherbrooke.ca/) and is now located at [McGill University](https://www.mcgill.ca/), Montreal._

`MEDomicsLab` is also the main laboratory behind the **MEDomics Platform**, which is a collaborative, open-source platform and solution for **medical data modeling** with one **unified dashboard** where clinicians and computer scientists work side by side to manage heterogeneous medical datasets, design and run experiments, and build predictive models.
